# Lanjarón audiogids

Website voor GitHub Pages met twee reeksen: Museo de la Miel (9 audio's) en wandeling (11 audio's). De hoofdfoto, foto's en audio's staan in `assets/`.

## Publiceren

Maak een openbare repository `Lanjaron-audiowandeling` op GitHub, upload **de inhoud van deze map** naar de hoofdmap van de repository, en zet onder Settings → Pages de bron op Deploy from a branch, branch `main`, folder `/ (root)`. De website verschijnt dan op `https://hugoroaen.github.io/Lanjaron-audiowandeling/` als de repository onder account `hugoroaen` staat.

## Route

Het definitieve GPX-bestand staat in `assets/route.gpx`. De pagina toont automatisch een kaart en downloadknop. Voor de kaart is een internetverbinding nodig.

De audiobestanden zijn uit de aangeleverde MP4's naar MP3 omgezet. Bij iedere halte hoort een foto met hetzelfde nummer. De titel bij wandeling 8 volgt de audio ('Tío Pedro'); de fotonaam noemde 'Tío Pepe'.
